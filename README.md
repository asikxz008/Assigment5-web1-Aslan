Nine responsive pages demonstrate JavaScript basics, DOM manipulation, and events. Each task has a separate HTML page and a short JavaScript file in `scripts/`. Navigation links connect every task.

Open `index.html` in a browser. No installation or build step is needed. Task 0 opens a greeting alert automatically; close it to use the page. Open the browser developer console with F12 to see output for Tasks 0 and 1.

| Page | Task |
| --- | --- |
| `index.html` | 0: external script, name/group in console, greeting alert |
| `task1.html` | 1: string, number, boolean, arithmetic, and concatenation |
| `task2.html` | 2: change paragraph text on click |
| `task3.html` | 3: change a block's background and font size |
| `task4.html` | 4: create list items and remove the last item |
| `task5.html` | 5: `mouseover` and `mouseout` color changes |
| `task6.html` | 6: live input preview using `keyup` |
| `task7.html` | 7: addition, subtraction, multiplication, and division |
| `task8.html` | 8: add, complete, and delete to-do tasks |

The calculator supports negative and decimal numbers, prevents division by zero, and displays up to 12 significant digits. The keyboard demo also listens for `input` so paste and mobile typing work. The to-do app stores objects in a temporary array; leaving or reloading clears it. Task text is inserted with `textContent`.

## Quick checks

- Task 0: close the automatic alert, check console output, and click Show Greeting.
- Task 1: check all three data types, arithmetic results, and the concatenated greeting.
- Tasks 2–3: change text and styles, then reset them.
- Task 4: add three items, remove the last, and remove the rest to check the empty state.
- Task 5: move over and out of the box; try Tab focus as well.
- Task 6: type, delete, and paste text; compare the preview and character count.
- Task 7: test the four operations, decimal/negative inputs, empty fields, and division by zero.
- Task 8: add tasks, toggle completion, delete tasks, reject spaces-only input, and reload to confirm temporary state.

Built with plain HTML, CSS, and JavaScript. No external libraries or services are required.
